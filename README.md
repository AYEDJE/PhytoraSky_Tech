# PhytoraSky Tech 

> **Drone intelligent multifonction pour relever les défis agricoles et environnementaux du Togo.**

Ce projet est une application web moderne (Landing Page One-Page interactive) développée avec **React 18**, **TypeScript** et **Vite**.

---

##  Démarrage rapide pour tester sur votre machine

### Prérequis
* [Node.js](https://nodejs.org/) (version 18 ou supérieure recommandée)
* `npm` (installé automatiquement avec Node.js)

---

### Installation et lancement en 3 étapes :

1. **Ouvrir un terminal** dans le dossier décompressé du projet :
   ```bash
   cd PhytoraSky_Tech-main
   ```

2. **Installer les dépendances** :
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement** :
   ```bash
   npm run dev
   ```

4. **Accéder au site** :
   Ouvrez votre navigateur web sur l'adresse affichée dans le terminal (généralement) :
   👉 **[http://localhost:5173/](http://localhost:5173/)**

---

## 🛠️ Commandes disponibles

* `npm run dev` : Lance le serveur local en mode développement avec rechargement à chaud (HMR).
* `npm run build` : Compile le projet pour la production dans le dossier `dist/`.
* `npm run preview` : Prévisualise localement le rendu de production compilé.
* `npm run typecheck` : Vérifie l'intégrité de tous les types TypeScript.

---

## 💡 Note pour le partage du projet
Si vous compressez ce projet en fichier `.zip` pour l'envoyer :
* **Ne pas inclure le dossier `node_modules` ni `dist`** (ils sont volumineux et seront recréés automatiquement par votre camarade grâce à la commande `npm install`).
